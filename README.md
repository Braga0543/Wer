# Аптека рядом

Трекер постоянных лекарств для людей с хроническими заболеваниями
в городе Атырау, Казахстан.

## Проблема

Люди с диабетом, гипертонией, астмой вынуждены каждый месяц искать
свои препараты по аптекам вручную. Существующие сервисы делают
разовый поиск, но не помогают планировать приём и не показывают
динамику дефицита лекарств по городу.

## Решение

- Регистрация пациента, данные доступны с любого устройства
- Личный список препаратов со схемой приёма
- Расчёт, когда закончится упаковка, и напоминание о покупке
- Карта аптек Атырау с наличием и ценой конкретного препарата
- Аналоги по действующему веществу
- Анонимные отчёты о дефиците и статистика по городу

## Стек

- Backend: Python + FastAPI, SQLite
- Авторизация: токены (PBKDF2-HMAC-SHA256 для паролей, токены сессий
  через `secrets.token_urlsafe`)
- Frontend: одностраничный HTML/CSS/vanilla JS, карта — Leaflet.js + OpenStreetMap

## Запуск

```bash
pip install -r requirements.txt
python db_setup.py
uvicorn main:app --reload
```

Открыть http://localhost:8000, зарегистрироваться, добавить препарат.

## Данные

Список аптек (названия, адреса, координаты, телефоны, часы работы)
взят из открытых карточек Google Places для города Атырау.
Наличие и цены конкретных препаратов в конкретных аптеках публично
не публикуются, поэтому в `db_setup.py` они сгенерированы случайно
для демонстрации работы приложения.
